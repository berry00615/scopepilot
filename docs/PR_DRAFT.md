# ScopePilot v1：离线研究工作台、受限工具任务与 Codex MCP

现有工作台按路径合并接口，不能区分多主机、协议和端口，也缺少可追溯工具来源与严格确认门槛。本次沿用 FastAPI / SQLite / Jinja2，补齐完整目标身份、多来源去重、评级与证据、HAR 被动检查、Nuclei/Gitleaks 导入、中文工作区和本地 stdio MCP。

- Codex 实际连接 12 个工具并调用成功；模型不能通过 MCP 确认发现或执行扫描。
- 固定官方 Nuclei 3.11.1、Gitleaks 8.30.1，只运行内置合成离线文件；支持取消提交边界、超时、输出总限、日志与原始来源校验。
- 参考固定提交的官方 Nuclei 定义，追加已有 HAR 的目录索引、Git/环境配置暴露检查；只保留结构信号，敏感正文整体省略，结果保持待复核。
- 最终本地 187 项回归通过；官方工具 6 轮与 Chromium 桌面/窄屏 9 组流程通过；v1 GitHub Python 3.11/3.13 检查通过。最终分支 CI 与测试记录见 docs/HANDOFF.md 和 docs/test-results.json。
- 依赖使用官方固定版本和 wheel 哈希；来源、许可证、磁盘记录、截图及复现方式见 docs/。

请保持草稿，不合并：拒绝代理已验证，但系统级禁止外联及任意后代进程清理尚未验收。不能把单元测试或代理拒绝当作系统隔离。主动目标请求关闭。
